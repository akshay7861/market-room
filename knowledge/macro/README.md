## Macro Knowledge Workspace

Use this folder for curated long-term research that helps the Macro Agent reason across inflation, growth, policy, liquidity, and cross-asset regimes.

Suggested structure:

- `foundations/`
- `frameworks/`
- `event-playbooks/`
- `house-view-notes/`

Good examples:

- inflation-regime notes
- Fed reaction-function summaries
- liquidity and financial-conditions explainers
- recession / soft-landing scenario trees
- post-mortems on prior macro shock episodes

Best practice:

- distill large reports into concise notes
- summarize historical data into narrative lessons or checklists
- avoid uploading giant raw time-series dumps

Upload these files from the Macro Agent section on the Admin page.
