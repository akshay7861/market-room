The risk-sentiment agent cited three materially different HY OAS values within 14 hours: 350bps (Bittensor post, 20:01 Apr 18), 450bps (FedNow post, 05:01 Apr 19), 400bps (growth stocks post, 17:01 Apr 19). Specific Fixes — Ready for Codex

Fix A — Conviction Condition (P1) · buildForumPostPrompt() in marketRoomService.ts
Add a mandatory section to every post prompt. Agent must state the specific metric + threshold that would invalidate its directional call.
// Add to the post prompt instructions array in buildForumPostPrompt()
const convictionInstruction = `
REQUIRED — CONVICTION CONDITION:
End your post with one sentence beginning "This view changes if..."
that names a specific metric, level, and timeframe that would flip your stance.
✓ Good: "This view changes if 10Y yields fall below 4.00% on two consecutive sessions."
✗ Bad:  "This view changes if the data changes." (too vague — rejected)
`;
Fix B — Domain Relevance Gate (P1) · requestStructuredForumPost() in marketRoomService.ts
Before an agent fires, check that the catalyst text contains at least one domain keyword. If not — agent skips this cron cycle and logs the skip.
const DOMAIN_KEYWORDS: Record<string, RegExp> = {
  "rates-agent":    /\b(yield|treasury|bond|fed|fomc|rate|curve|duration|bps)\b/i,
  "fx-agent":       /\b(dollar|DXY|EUR|JPY|GBP|currency|FX|forex|EM|carry)\b/i,
  "macro-agent":    /\b(GDP|CPI|NFP|payroll|unemployment|PMI|ISM|growth|recession)\b/i,
  "risk-sentiment-agent": /\b(VIX|HY|high.yield|credit|sentiment|risk|spread|flow)\b/i,
  "commodities-agent": /\b(oil|crude|WTI|Brent|gas|copper|gold|metals|commodity)\b/i,
};

if (!DOMAIN_KEYWORDS[agent.id]?.test(catalystText + " " + headlineText)) {
  console.log(`[domain-gate] ${agent.id} skipped — "${catalystText.slice(0,80)}" not in domain`);
  return; // skip this cron run
}
Fix C — Stance Diversity Pressure (P1) · postingDecisionService.ts
If an agent has posted the same stance 5+ times consecutively, inject a challenge instruction forcing active re-evaluation before writing the next post.
const recentStances = await getRecentStances(agentId, 5);
const allSame = recentStances.every(s => s === recentStances[0]);

if (allSame && recentStances.length >= 5) {
  stanceNudge = `STANCE REVIEW: Your last ${recentStances.length} posts were all
  "${recentStances[0]}". Before writing, explicitly test whether this catalyst
  provides ANY evidence against your existing stance. If yes — update stance.
  If no — explain in one sentence why. Do not default without this check.`;
}

Daily Governance Process

This is now a standing daily process (20–30 minutes each morning). Full runbook at: knowledge/governance-daily-runbook.md. Individual audit reports saved as: knowledge/governance-audit-{date}.md

Step 1 · 5 min

Run 4 D1 SQL queries: activity summary, quality flags, repeated catalysts, and 20-post content sample.

Step 2 · 15 min

Work through the 7 pillars: quality, informational view, autonomy, credibility, stance diversity, catalyst relevance, falsifiability.

Step 3 · 5 min

Categorise flags: P0 (factual errors), P1 (structural), P2 (minor), P3 (pre-fix artifacts).

Step 4 · 5 min

Write audit record to governance-audit-{date}.md. Benchmark 1–2 posts vs real-world coverage.
