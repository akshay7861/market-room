## What Each File Adds

### FX — Dollar Funding Stress and Intervention Playbook

This completes the FX agent's Batch 3 layer by giving it a way to distinguish:

- normal divergence-driven USD strength,
- technical basis widening,
- true offshore dollar shortage,
- and intervention credibility.

The main value is not "stress exists." It is the mechanism split between policy divergence, funding scarcity, and official containment. That should materially reduce the risk of the FX agent mislabeling a plumbing crisis as a simple hawkish-dollar trade.

### Risk/Sentiment — Risk-On / Risk-Off Transmission Guide

This completes the Risk/Sentiment stack by adding the cross-asset map beneath the existing crowding and volatility docs. Batch 1 explained fragility conditions; Batch 2 explained regime activation through volatility. This new guide explains:

- how risk-off usually transmits,
- which assets should confirm it first,
- how to tell a temporary wobble from a full regime shift,
- and how to name fractured correlations instead of forcing a textbook risk-off call.

### Equities — Earnings Quality and Margin Pressure Interpretation Guide

This completes the Equities stack by adding the bottom-up filter beneath the Batch 1 regime framework and Batch 2 leadership playbook. The new contribution is not "earnings matter." It is:

- how to separate clean earnings from low-quality beats,
- how to recognize gross-margin deterioration early,
- how to connect PPI and pricing power to future sector performance,
- and when a rally is being driven by liquidity rather than true earnings quality.

## Overlaps or Weak Areas Still Remaining

### Intentional overlaps

- FX overlaps with the carry and divergence docs by design because funding stress is the exception regime that overrules both.
- Risk/Sentiment overlaps with the vol and crowding docs intentionally because risk-on / risk-off transmission is the cross-asset base layer beneath both.
- Equities overlaps with the regime and leadership docs intentionally because earnings quality decides whether a regime move is actually durable.

### Weak areas still remaining

1. **Wave 2 still lacks a deeper analog library**
   - The docs include historical episodes, but those episodes are not yet broken out into reusable analog-case assets.

2. **Risk/Sentiment still has lighter coverage of crypto and systematic-flow transmission**
   - The current stack is strong for traditional cross-asset risk but lighter on crypto-specific or options-flow-specific spillovers.

3. **Equities still has limited single-sector accounting nuance**
   - The earnings-quality guide covers the broad hierarchy well, but financials, semis, and healthcare could later use deeper sector-specific quality add-ons if needed.

4. **FX still does not have a dedicated EM balance-of-payments crisis guide**
   - The intervention playbook is enough for Wave 2, but a future library could go deeper on reserve adequacy and external-financing stress in EM.
